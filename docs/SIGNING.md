# Free or near-free Authenticode signing for nioh3p (`dinput8.dll`)

All sources were checked on 2026-10-21. Only the provider's own page counts as proof. Anything else is marked **[secondary]**, **[INFERENCE]** or **[UNVERIFIED]**. A price or rule seen today may change later.

## Summary

- Only two programs give a free, publicly trusted Authenticode signature: **SignPath Foundation** and **OSSign**. Both sign with their own certificate, and both review the project's reputation. OSSign is not accepting applications at the moment. Today, nioh3p would probably fail SignPath's reputation and naming checks.
- **Certum Open Source Code Signing** has no free tier. The cheapest new option is **€49 for the cloud version**. That is above the ~10 USD/year limit.
- **Azure Artifact Signing** has no free tier. It costs **$9.99/month**, and individuals must live in the US or Canada. Free, trial and sponsored Azure subscriptions (credits) are not accepted.
- **No help:** self-signed certificates, Sigstore/cosign, GitHub artifact attestations and Let's Encrypt. None of them produces an Authenticode signature that chains to a root Windows trusts.

### What each verified fact means for the Windows friends

- **SmartScreen:** a trusted signature shows a named publisher. Warnings fade as reputation builds. EV no longer skips this step [8][4].
- **Smart App Control (Windows 11):** if the cloud check cannot decide, SAC lets a file run only if it has a valid signature. It blocks unsigned files and does not allow per-app exceptions [24]. Microsoft says SAC signature checks apply to all executable files [8]. **[INFERENCE]** A friend with SAC on would be blocked from loading the unsigned DLL. This is the strongest technical reason to sign.
- **Defender ML detections** (e.g. `Wacatac.C!ml`): Microsoft runs no allow-list program for developers. Its fix is the "Software developer" file submission [10][26]. Signing helps analysts and can lead to faster known-list entry. It is not a guarantee [10].
- **Repo claim to fix:** `docs/FP_REPORTS.md` line 9 says "If the code is signed, this type of detection does not occur." No source supports that as an absolute. Microsoft only says signing *helps* [10]. No third-party vendor source was found.

## Recommendation (three friends now, Nexus later)

1. **Now: do not pay, and do not self-sign.** No free program will take nioh3p today. SignPath needs public reputation, and OSSign is closed and needs 6 months of public history. Keep the DLL unsigned. File the free false-positive reports: Microsoft "Software developer" submission [26], plus the Avast/Avira/WithSecure forms already in `docs/FP_REPORTS.md`. Publish the SHA-256 (and optionally a GitHub attestation) so the friends can check the file. Ask the two Windows friends whether Smart App Control is on, because it blocks unsigned files outright [24].
2. **Before Nexus, set the project up for SignPath (free).** Steps: add an OSI license (MIT or GPL-3.0); make the GitHub repo public; build `dinput8.dll` in GitHub Actions on GitHub-hosted runners with zig or mingw; publish an unsigned release; add a "Code signing policy" section, a privacy statement ("no network connection of its own" already fits) and uninstall steps; turn on MFA. Pick an unambiguous project name that qualifies the game name rather than relying on "Nioh" alone, for example "<handle>'s Nioh 3-Player Co-op". Accepted names like "Balatro Mod Manager" show this can pass, but SignPath decides [3][6]. After the Nexus page has real downloads, endorsements and some outside mentions, apply at signpath.org/apply. Expect weeks, not days, and a possible rejection [S1]. Re-check OSSign at the same time. It may reopen, and it does not put a real name on the certificate [7].
3. **Paid fallback, only if Smart App Control or AV blocking becomes a real problem first:** Certum OSS in the cloud, €49 [13]. Your real name goes on the certificate, the project must be non-commercial, and signing is manual on Windows [15][16]. Azure Artifact Signing (~$120/year) applies only if the signer is an individual living in the US or Canada [21].
